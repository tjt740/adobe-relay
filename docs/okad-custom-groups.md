# Okad 自定义分组（配套发布）

需与 Okad 自定义分组版本配套发布。网站每日更新日志按本次实际发布的北京时间日期记录；发布结果和回退信息见主服务器发布审计。

- Okad 导入时可创建和选择自定义分组，已有账号可批量改组。公司、越南、非公司账号类型与分组分别筛选。
- Sub2「账号管理」增加「Okad 创建的分组」，选项来自所有已同步账号，不受当前分页影响。与原 Sub2 业务分组独立，可组合账号类型、状态等查询条件；列表、实时更新、导出、账单快照和筛选批量操作均传递同一条件。
- `okad_account` 元数据新增 `account_type`、`group_id`、`group_name`。分组以 Okad 实例和分组 ID 识别，避免不同实例同名或同 ID 混淆。缺失或身份不一致的元数据仍为待识别，不算未分组。
- 沿用专用联动元数据接口；普通管理员连接可使用 `/admin/accounts/okad-metadata`。该接口只更新归属标记，不修改 Cookie、代理、调度或业务分组，不发起 Adobe 请求。Okad 改组在本地提交后同步，失败保留本地结果，可靠模式沿用定时重试；普通连接恢复后重新保存分组即可重试。
- Sub2 无数据库迁移。Okad 自动新增分组表及可空的 `external_members.group_id`，原有账号、凭据及状态保留。

本地验证：Go 分类／元数据及跨页筛选、导出、批量操作测试；前端分类、筛选控件、接口传参、页面集成和 i18n 测试；TypeScript 检查。Okad 另有隔离数据库迁移和桌面／手机、根路径／`/okad/` 浏览器回归。全部使用合成数据，未操作生产账号。
