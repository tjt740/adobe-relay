# 账号手动 IP 设置（开发完成，尚未部署）

本次功能在 `codex/account-manual-ip-20261023` 工作树开发，基于主干 `39528634e`。没有推送、部署或修改生产配置、账号、代理与订阅。

## 使用行为

账号编辑 → 代理 →「手动 IP 设置」。默认关闭；开启后选择代理并点击「更新」一起保存，取消不保存。无代理表示手动选择直连。影子账号继续继承母账号出口，不能独立设置。

开启后，普通自动分配、延迟优化、独立故障切换、过期代理回退和 408 代理释放跳过该账号。检测、额度查询与续期不借用或替换其代理。手动绑定计入节点已占容量，不能被其他账号或临时检测回收；不强制重新分配用户指定的出口。关闭开关后恢复现有自动规则，尚未恢复的 408 账号会再次进入原隔离流程。

固定 IP 不清除 408、凭据错误或验证证据，不自动恢复调度，也不改变人工暂停、分组或 Cookie 恢复规则。显式删除代理或订阅继续沿用原清理保护，避免残留无效引用。

## 实现

- 编辑接口增加可选布尔参数 `manual_proxy_enabled`；账号读取沿用 `extra.manual_proxy_enabled`，缺失视为关闭。随代理修改在同一次账号更新中提交。
- 迁移 `252_account_manual_proxy.sql` 仅替换自动分配触发器，不批量改写账号或删除数据。手动模式允许保存指定出口；退出模式时恢复触发器的原校验。
- 在数据库锁内保留最新手动模式；后台旧快照不能改变该模式或覆盖已固定的出口。管理员明确选代理时仍能修改。
- 在后台分配、独立切换的加锁复核、408 记录与释放、检测租约申请和收尾处分别判断当前模式，防在途任务覆盖后来的人工选择。
- 中英文更新日志放在 `pendingDailyUpdates`，不展示为已上线。实际发布时按北京时间移入当天并更新当天概览，跨午夜调整日期。
