## 登录和访问控制

- 直接使用 Sub2 原有 `/api/v1/auth/login`、`/auth/login/2fa`、`/auth/me` 和 `/auth/logout`。每次返回正文或 Markdown 前由 Sub2 校验当前账号/会话，不复制用户库，不按管理员角色限制普通注册用户。
- 未登录、双重验证未完成、账号停用/删除、密码变更导致令牌撤销、过期或身份验证服务异常，均不返回文档正文。登录页和样式/交互脚本不含受保护文档。
- 浏览器只有随机 `__Host-docs_session`，Secure/HttpOnly/SameSite=Strict、无Domain属性；Token/刷新令牌仅在有界进程内存。密码仅用于当次登录转发，不记录/落盘。会话最长一小时并受原Token期限、IP/UA约束；退出或服务重启失效。响应禁止缓存与索引，限制跨站表单和嵌入。
- 当前 Sub2 CAPTCHA 均关闭；将来若开启，原后端验证会拒绝缺少证明的登录，需要配套接入对应小组件，不能绕过原验证。
- 支持章节搜索、代码复制、Markdown下载、窄屏样式；旧 `/docs/batch-image` 转到现有 `/batch-image`，www文档访问规范到creative.cheap。
