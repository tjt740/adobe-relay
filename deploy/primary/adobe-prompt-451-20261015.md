# Adobe 提示词违规返回 HTTP 451

本次仅修改 Sub2 的 Adobe 内容安全错误识别和对外状态码。明确的 `prompt_unsafe`、`image_unsafe` 最终向调用方返回 HTTP **451**，保留原 `error.type: adobe_content_rejected` 和安全提示文案。普通参数错误仍为 400；鉴权、额度、模型权益和临时故障保留原分类。提示词违规不清除 Token、不触发凭据恢复，也不冷却账号；原有中转尝试策略保持。

```json
{
  "error": {
    "type": "adobe_content_rejected",
    "message": "Image content was rejected by the upstream safety filter"
  }
}
```

图片 URL、真实 `usage` 或 `null` 的返回方式、计费及其他已上线功能保持，本次不添加估算字段，无数据库迁移，不更新 Okad 或业务设置。

## 验证

本地带 race 的客户端、错误分类和图片 handler 相关回归通过，覆盖提交与轮询的提示词违规、上游 200 终态失败、400/401/403/451 分类、最终 HTTP 451、安全错误文案和原并发/交付逻辑。使用模拟上游响应，未向 Adobe 发送违规提示词。正式发布沿用主服务器工作流及其后端、数据库、SMTP 和前端检查。
